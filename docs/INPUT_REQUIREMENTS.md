# 工程资料接入清单

包含的样例和规则均为合成软件测试材料，不能代替真实工程批准依据。先以一个已支持检查类型的场景开始。

最小可开始的一组：

- 输入文件及允许使用的范围，软件名称/版本、工作表和字段定义。
- 明确的对象关联、量纲、单位、缺失值和重复记录处理要求。
- 检查方法、适用条件、参数、容差与批准版本；提供原始引用。
- 与被测系统独立的预期结果，预期问题和负责技术验收的工程师。

接收后先保存原文件及hash，预览适配配置和单位，再建立不可变快照；导入规则包、核对来源并按权限批准。用独立案例运行评测，记录漏检、误报、错误通过及证据不足。输入或规则变化后关联重检并重新人工审核。具体代码入口见[适配指南](../CLIENT_ADAPTATION.md)。

后续补充：更广的正确/错误/缺资料样例、授权的CSI只读接口、Windows和ETABS/SAFE许可环境、扫描件校对责任、部署和备份要求。未给出的单位、阈值、规范权威或预期答案不能自行猜测；超出现有工具的工程方法需新增工具和独立验证。
