## 实施记录

1. **数据适配**：新增 `adapters.py`；保存不可覆盖的 ID / 版本，预览、应用、导出；显式别名 / 类型 / 必填 / 单位与有限转换。CSV / XLSX / JSON 来源可追溯；失败保持原文件，不创建半快照。单位未知、重复别名、未知列和公式均拒绝。
2. **规则包**：新增 `contracts.py` 和 `adaptation_api.py`；全量预检、准确文本 / hash、包导入 / 导出、导入重置草稿、局部批准。只支持已实现工具；条件未知不能通过；禁止代码和任意公式。
3. **案例评测**：新增 `cases.py`，原队列承载批量；预期答案独立声明、不可覆盖版本、案例 / 输入 / 规则绑定、预期副本 hash。逐项与总体指标分开。排队中不伪装成成功或最终漏检指标。
4. **材料与人工复核**：新增 `evidence.py`，网页 / HTML / JSON 展示需求位置；复用 corrections / resume / issue resolution。修订后确认失效，原审核记录保留。补强 run 导出与实际被检输入 hash 的一致性校验。
5. **安装交付**：新增 doctor 和完整适配演示；沿用锁定依赖与安装脚本，无新依赖；Node 最低版本明确为 20.11，交付版本改为 1.1.0。包不带运行账号、数据库、原客户资料、模型或 proposal。
6. **交接**：新增中文 `CLIENT_ADAPTATION.md`、`NEXT_SESSION.md`，更新安装说明与 API 功能位置。

技术选择沿用 FastAPI / SQLAlchemy / SQLite、原生英文前端、现有 Node 数值工具。配置资源复用现有 Resource 表，批量复用原 worker。没有引入多 Agent、向量库、微调或第二个框架；当前缺口主要是确定的数据 / 规则接口，而不是增加模型能力。

## 调试中发现并修复

规则包预检最初从尚未落盘的来源 hash 读取内容，完整演示捕获了 FileNotFoundError。改为以包内经过 hash 校验的原字节进行只读预检；数据库在全量预检后才写入。覆盖了准确引用失败时不留部分文件 / 规则的测试。首次测试还有一处用“最后一条规则必有 parameters”的错误测试假设，已改为选择参数规则。更正来源测试还修正了测试请求的 source_locator 字段与数值原值类型，沿用既有 API 契约。当前测试无遗留失败。

真实工程准确率、客户标准合规、商业竞争力和生产可用性没有实测结论。

最终包空环境回归曾因缺少模块路径在收集阶段失败。补入根目录 `pytest.ini` 的 `pythonpath = backend`，让文档中的直接 pytest 命令跨平台使用同一入口；随后在干净虚拟环境重新验证。
