# Security

Do not include real project data, credentials or account databases in public issues. Report vulnerabilities through the repository's private vulnerability reporting channel when available. Include a minimal synthetic reproduction and affected version; no response-time guarantee is implied.

STRATA runs locally by default. It separates project membership and viewer/engineer/reviewer actions, retains source provenance and rejects unsupported engineering execution. It is not a certified engineering approval system. Network exposure, access policy and real-engineering acceptance require separate deployment/review work.

Keep runtime files and backups private. Do not expose bootstrap setup tokens, execute arbitrary uploaded code or disable permission/evidence validation to make a check pass. Verify restore operations in an isolated directory first.
